## Limits

This validates the current XML UI with Compose support enabled. No screen is using Compose yet, so this is not runtime validation of migrated Compose screens. Password reset checks sending and showing confirmation; it does not follow an email link to change the password. Live exchange-rate retrieval, airplane-mode/offline reconciliation, process-death draft restoration, denied-permission recovery, exhaustive accessibility, every form option, and physical-device/API-matrix behavior were not exercised. Activity recreation is covered; it is not equivalent to process death.

Lint warnings remain, primarily unused resources, hardcoded text, unused attributes, overdraw and missing content descriptions. No lint cleanup was included in this testing task.
